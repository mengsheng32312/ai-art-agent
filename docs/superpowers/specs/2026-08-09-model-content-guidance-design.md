# 模型内容筛选与新手选模设计

## 目标

在生成参数页让用户先选择准备生成的内容，再用该选择缩小模型范围，避免仅凭英文模型名选错模型。第一版支持：人物、风景、动漫、产品/静物、建筑/室内、通用。

## 模型标签

模型能力档案增加 `content_tags` 字段。标签来源按以下顺序确定：

1. 用户在模型管理中保存的标签。
2. 根据模型名称、文件名和中文说明匹配内置关键词规则。
3. 无法可靠识别时标记为“通用”，不强行分类。

内容标签只描述模型擅长生成的题材，不替代现有的文生图、图生图、文生视频等能力校验。

## 生成参数页

在创作任务与模型选择之间增加“想生成的内容”单选项，并增加“新手选模”开关，默认开启。

- 开启时：模型必须先满足当前创作任务，再保留包含所选内容标签或“通用”标签的模型；精准匹配排在通用模型之前。
- 关闭时：只按当前创作任务筛选，不按内容标签过滤。
- 切换内容分类后，如果当前模型不再可见，则清空模型选择，防止提交错误模型。
- 模型下拉项显示内容标签，帮助用户理解推荐原因。
- 没有匹配模型时显示明确空状态，不自动选择不匹配模型。

该筛选只影响 checkpoint 主模型，不筛选 LoRA、VAE、ControlNet 和运动模型。

## 模型管理

能力设置中增加内容标签多选项。保存后沿用现有模型能力档案接口持久化，并立即影响生成参数页筛选。

## 数据与兼容

后端 `ModelCapabilityProfile` 增加默认值为 `['general']` 的 `content_tags`。现有已保存档案缺少该字段时按默认值加载，避免破坏旧数据。

前端生成请求不新增字段；内容分类只负责辅助选择模型，最终仍由现有模型文件名和创作任务发起生成。

## 错误处理

- 无匹配模型：提示“当前内容分类暂无合适模型，可关闭新手选模查看全部兼容模型”。
- 未识别模型：作为通用模型显示，不宣称其擅长特定题材。
- 标签被修改：重新筛选，并在当前模型不再匹配时清空选择。

## 验证范围

- 后端内容标签推断、默认值与本地保存读取。
- 前端内容分类筛选、精准匹配排序、开关关闭行为和不匹配模型清空。
- 模型管理内容标签编辑与保存。

不执行无关模块的完整回归、重新打包或重新安装。
