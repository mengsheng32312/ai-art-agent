# MVP 边界问题修复设计

## 目标

修复最终代码审查发现的用户可见边界问题，同时保持当前轻量架构，不进行 Pinia、Vue Router、页面拆分或后端分层重构。

## 1. Agent 端口与身份校验

- Agent 继续使用 `127.0.0.1:8000`，本轮不引入动态端口协议。
- `/api/health` 返回 `status`、固定服务标识 `ai-art-agent` 和应用版本。
- 前端只有在状态、服务标识和版本结构有效时才认定 Agent 已启动。
- Tauri 启动 Agent 前检查 8000 端口；端口已被外部进程占用时返回明确中文错误，不连接未知服务。
- 已由当前应用托管且仍存活的 Agent 直接复用；已退出的子进程从状态中清除。

## 2. ComfyUI 托管生命周期

- 原生层记录托管 ComfyUI 的规范化根目录和子进程。
- 相同目录重复启动时直接复用，不再次创建进程。
- 切换到不同本地目录时，先有界停止旧托管进程，再启动新进程。
- 切换到远程模式时，只停止由本应用启动的 ComfyUI，不停止 Agent，也不影响用户手动启动的进程。
- 本地模式先完成目录验证和启动，再持久化配置，避免启动失败但配置已保存。
- 新增仅停止托管 ComfyUI 的原生命令。

## 3. 使用当前表单测试连接

- 测试连接不读取后端已经保存的旧配置。
- 后端提供接收候选配置的连接测试接口，不持久化该配置。
- 前端把当前表单中的模式、URL 和目录作为候选配置提交。
- 连接成功不会自动保存；“保存”和“测试连接”保持两个明确动作。

## 4. 任务异常状态与轮询恢复

- 后端区分 ComfyUI 队列中的 pending、running、completed 和 execution error。
- 任务既不在历史也不在 pending/running 队列时，连续三次确认后标记为失败，并给出“可能已取消或中断”的中文错误。
- ComfyUI 网关暂时不可用时返回结构化 502，不把任务错误地改成失败，也不累计“队列消失”次数。
- 前端轮询遇到临时错误后继续重试，延迟逐步增加并限制最大间隔；下一次成功后清除临时连接错误。
- execution error、队列消失和暂时连接失败分别展示，不把三者混为同一错误。

## 5. 多图结果

- 遵循 `2026-07-30-multi-output-gallery-design.md`。
- 当前任务和历史记录都遍历 `outputs`，显示全部图片。
- 保留 `batch_size` 1–8，不增加灯箱、分页或下载功能。

## 6. 进程退出清理

- Windows `taskkill /T /F` 必须检查返回状态。
- `taskkill` 失败时回退到 Rust `Child::kill()`。
- 使用 `try_wait()` 和固定截止时间等待退出，不再无界调用 `wait()`。
- 超时或失败通过 Tauri 命令返回明确错误；应用不得无限卡在退出流程。
- Agent 和 ComfyUI 使用同一套有界终止逻辑。

## 7. 架构与文档收敛

- 保留当前 `frontend/src/App.vue` 和 `backend/app/main.py` 的集中式 MVP 实现。
- 不为了匹配早期计划而重构 stores、views、routes 或 `GenerationService`。
- 更新原实施计划：状态改为已完成，记录 NSIS-only 和用户批准的简化架构。
- 移除当前未承担状态管理职责的 Pinia 初始化和依赖，避免文档与代码暗示不存在的分层。

## 数据与兼容性

- 现有配置 JSON 和历史 JSON 格式保持兼容。
- 现有生成 API 的成功响应保持兼容；仅健康接口增加字段，连接测试增加候选配置入口。
- 不修改 ComfyUI 工作流 JSON，不下载模型或节点。

## 测试策略

- 后端：候选配置不持久化、网关 502、队列消失三次后失败、暂时异常不累计消失次数。
- 前端：当前表单值用于测试连接、临时轮询错误会重试并恢复、多图结果和多图历史全部显示。
- Rust：相同路径复用/不同路径重启决策、端口占用判断、有界进程终止辅助逻辑。
- 每项遵循先失败测试、后最小实现；开发中只运行相关测试，全部修复后运行一次前后端及 Rust 回归测试。

## 验收

- 未知进程占用 8000 时不会显示 Agent 已连接。
- 重复保存同一本地目录不会重复启动 ComfyUI；切换远程会停止托管 ComfyUI。
- 测试连接使用未保存的当前表单值且不会持久化。
- 取消、消失或短暂断线不会让界面永久停在错误状态。
- 批量任务返回几张图，结果和历史就展示几张。
- 子进程清理失败不会让应用无限等待。
