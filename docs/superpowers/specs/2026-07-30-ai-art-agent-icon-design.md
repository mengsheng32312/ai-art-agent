# AI Art Agent 应用图标设计

## 状态

已批准（2026-07-30）

## 目标

为 AI Art Agent 提供一个简洁、可识别的 Windows 桌面应用图标，补齐 Tauri 构建所需的 `src-tauri/icons/icon.ico`，同时与现有深色创作界面保持一致。

## 视觉设计

- 深海军蓝色的圆角方形底板。
- 中央使用蓝紫渐变的四角星芒，表达 AI 创作与生成。
- 星芒下方融合一笔简化画笔笔触，表达艺术创作。
- 不包含文字、字母、人物或复杂纹理。
- 构图居中，四周保留充足安全边距，确保 16×16 像素下仍能辨认。
- 风格为干净的现代应用图标，使用清晰轮廓和有限层次，不采用照片质感。

## 色彩

- 背景：深海军蓝，接近 `#0B1020`。
- 主体：电光蓝到紫罗兰的渐变。
- 高光：少量浅蓝白色，只用于增强星芒中心的层次。

## 交付资产

- `src-tauri/icons/icon.png`：1024×1024 主源图。
- `src-tauri/icons/icon.ico`：包含 16、24、32、48、64、128 和 256 像素尺寸的 Windows ICO。

## 生成与验证

- 使用内置图像生成工具生成无文字的 1024×1024 主图。
- 检查主体、色彩、居中构图和小尺寸辨识度。
- 将主图转换为多尺寸 ICO。
- 重新运行 Tauri Rust 测试，确认 build script 不再因图标缺失失败。
- 后续品牌升级可以替换图标，但不扩大本次 MVP 的视觉范围。
