# 引导式创作流程设计存档

存档日期：2026-08-09

## 当前确认

- 整体流程方向基本确定。
- 流程按照用户决策顺序组织，不照搬 ComfyUI 节点执行顺序。
- 每个可见步骤必须新增节点组、替换节点组或修改关键节点输入。
- 节点名称作为辅助信息展示，主要交互使用通俗中文。
- 不需要的步骤自动跳过，并重新计算步骤编号。
- 模型、采样器、VAE 等技术组件在需求明确后自动匹配。
- 只能承诺提交前检查通过，不能承诺运行期绝不报错。

## 当前流程

1. 选择任务：文生图、图生图、文生视频、图生视频、视频重绘或导入工作流。
2. 按任务上传必要素材；纯文字任务自动跳过。
3. 描述主体、环境、动作和画面感觉，组合到提示词节点。
4. 选择是否保持人物长相、姿态、构图或风格，只显示已验证能力。
5. 选择图片比例与数量，或视频比例与时长。
6. 系统组合模型、采样、解码和输出节点，检查后提交 ComfyUI。

## 已完成联动

- 图片与视频任务切换后，素材类型、动作提示和成品规格同步变化。
- 参考人物长相等选项显示实际节点连接路径。
- 原素材任务默认跟随原素材比例。
- 导入 ComfyUI 工作流 JSON 后保留原始节点，直接进入执行图检查。
- 当前步骤展开，完成步骤折叠，节点之间保留明确间距与动画。
