# ComfyUI Manager 内部窗口设计

## 目标

把 ComfyUI Manager 入口从“远程模型”分类移到模型管理顶部，并通过软件内部独立窗口加载完整 ComfyUI 原界面，让用户沿用原版模型预览和下载流程。

## 顶部入口

模型管理顶部工具栏显示 Manager 状态和操作：

- Manager 不可用且为本地连接：显示“一键启用 Manager”。
- Manager 可用且 ComfyUI 已连接：显示“打开 ComfyUI 模型库”。
- 远程连接的 Manager 不可用：只显示不可用状态，不提供远程安装操作。
- Manager 启用入口不再藏在“远程模型”分类中；该分类只负责展示在线模型库。

## 内部窗口

桌面端新增一个固定标识的 Tauri WebviewWindow，加载当前配置中的 ComfyUI API 地址。

- 窗口展示完整 ComfyUI 原界面，不复制或注入 Manager 内部组件。
- Manager 没有稳定的独立页面地址，因此用户从 ComfyUI 原界面的 Models/Manager 入口进入。
- 同一时间只允许存在一个窗口；重复点击时聚焦现有窗口。
- 地址变化后再次打开时，关闭旧窗口并使用新地址创建窗口。
- Web 端运行时不创建桌面窗口，改为在新的浏览器标签页打开 ComfyUI。

## 下载与目录

模型下载完全由 ComfyUI Manager 执行。它根据模型类型保存到 ComfyUI 自己的模型目录，或 Manager 配置的 `download_model_base` 路径。

- 本地连接下载到本机 ComfyUI。
- 远程连接下载到远程 ComfyUI 所在设备。
- 本软件不要求用户为每个模型选择保存目录，也不接管 Manager 的下载请求。

## 状态同步

- 打开内部窗口前必须确认 ComfyUI 已连接且 Manager 可用。
- 内部窗口关闭后，模型管理页重新请求模型目录。
- 主窗口重新获得焦点时，如果曾打开 Manager 窗口，也重新请求模型目录。
- 刷新只更新模型列表和安装状态，不重启 ComfyUI。

## 错误处理

- ComfyUI 未连接：提示先完成连接，不创建窗口。
- Manager 未启用：提示先启用 Manager。
- 地址无效或窗口创建失败：在当前页面显示中文错误。
- 远程页面无法访问：内部窗口保留 ComfyUI 原始错误页面，主页面连接状态不被误改。

## 验证范围

- 顶部 Manager 状态与按钮显示条件。
- 本地一键启用入口仍可工作。
- 桌面窗口首次创建、重复点击聚焦和地址变化重建。
- Web 端回退为新标签页。
- 内部窗口关闭或主窗口重新获得焦点后的模型刷新。

不执行无关模块的完整回归、重新打包或重新安装。
